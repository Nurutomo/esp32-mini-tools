Send a note
to the screen.

Flash the ESP32-C3 SuperMini, then send text over Bluetooth LE to render it on a small I²C OLED.

01 / INSTALL

Flash firmware

Connect the ESP32-C3 by USB. Use a Chromium browser on HTTPS or localhost.

Firmware is built and published by GitHub Actions.
02 / SEND

Write over BLE

Connect to ESP32-C3-OLED. Text is sent as UTF-8 to the device's write characteristic.

Bluetooth requires a supported Chromium browser and HTTPS.
